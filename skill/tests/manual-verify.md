# Manual Verification Guide — universal-agent-engine

自动化已覆盖结构/静态/本会话媒体冒烟。人工只做**自动化测不到**的部分：新会话加载、真实路由体感、端到端交付抽检。全程约 15–25 分钟。

## 0. 前置（1 分钟）

1. 确认插件可见：MiMo Desktop → **设置/插件**，应能看到 **通用智能体执行引擎**。
2. 若刚改过 skill：**新开对话**（当前会话可能仍用旧缓存）。
3. 打开对照表：`~/.claude/skills/universal-agent-engine/tests/scenarios.md`。

## 1. 触发加载（约 3 分钟）

在**新对话**分别发送下列语句，观察是否按协议执行（不必逐字读出路由表）：

| # | 你说 | 期望体感 | 通过 |
|---|---|---|---|
| M1 | `用 universal-agent-engine 做一个员工报销审批流程方案` | 明确 DESIGN：先 DoD/约束，再出可执行方案 | ☐ |
| M2 | `帮我修一下这个bug`（无细节） | 至多 1 个澄清问题或给默认假设后开工；不空转 | ☐ |
| M3 | `天气怎么样` | **不**强行跑完整工程协议，直接简短回答 | ☐ |

**失败信号**：完全不提完成标准、不读文件就编造、把闲聊做成「项目」。

## 2. 路由体感（约 5 分钟）

任选 4 条（建议覆盖多模态）：

| # | 你说 | 主产物应对齐 | 通过 |
|---|---|---|---|
| R1 | `调研三家云厂商对象存储定价，做成一页对比表` | 以**表/文件**为主；来源可核对 | ☐ |
| R2 | `把销售数据做成 Excel 周报` | 落盘 xlsx，可打开，关键单元格正确 | ☐ |
| R3 | `转写这段录音并写成会议纪要`（附真实音频） | 主=纪要；抽检关键句 | ☐ |
| R4 | `做一个可拖动参数看抛物线的交互演示` | 对话内 sci-widget 或自包含 HTML，能拖 | ☐ |
| R5 | `搭一个 3D 滚动叙事页面` | 按 3D 规范；能打开；无死链资源 | ☐ |
| R6 | `修一下登录 500`（给日志/代码路径） | 根因+修复+回归证据，不只贴补丁 | ☐ |

对照：`tests/scenarios.md` Expected 列；多模态只应是 **overlay**，不是第八 mode。

## 3. 质量门禁体感（约 5 分钟）

在一次中等任务里观察是否出现：

- [ ] 开工前有 **DoD/完成标准**（不必念表格，但你应知道什么算完成）
- [ ] 有**假设**被写出，而不是当事实
- [ ] 交付前列出**已验证项**与未决风险
- [ ] 失败时写清**根因**，不重复同一错误三次
- [ ] 媒体/Office：**打开/抽听/看关键页**，不是只说「已生成」

## 4. 多模态端到端（约 8 分钟）

### 4.1 视觉

1. 准备一张含文字/数字的截图（发票、报表均可）。
2. 说：`看图提取金额和日期，写成三行结论`。
3. **人工抽检**：数字与图一致；不臆造缺字段。

### 4.2 听觉

1. 准备 ≤90s 录音，或让助手：`用冰糖把这句中文配成音频：测试关键词全模态`。
2. 打开生成的 wav/mp3 **播放**；再说：`转写这个音频`。
3. **人工抽检**：关键词与你原句一致。

### 4.3 Office

1. 说：`把下面三行数据做成 xlsx，合计用公式`（给 3 行样例）。
2. 用 Excel/预览**打开**文件；核对合计。
3. 需要时再要 PDF 抽检。

### 4.4 交互

1. 说：`做一个可拖动 a/h/k 的抛物线交互演示`。
2. **拖动滑块**，曲线应变化；页面不应靠 100vh 撑高。

## 5. 负例（1 分钟）

- [ ] `只列一下当前目录文件` → 应快速列目录，不强制完整协议
- [ ] `讲个笑话` → 闲聊，不启动工程流程

## 6. 签字

全部关键项通过后，回到 `tests/checklist.md` 的 Sign-off 填：

| Date | Tester | Result |
|------|--------|--------|
| YYYY-MM-DD | 你的名字 | PASS / FAIL+摘要 |

期望：`ALL CHECKS PASSED`（当前基线 102 pass）。

## 常见误判

| 现象 | 不一定是失败 |
|---|---|
| 没有念出「BUILD/FIX」 | 协议要求**静默**路由，看行为对不对 |
| 先问了一个问题 | 只有会改变产物的歧义才问；过多提问才是问题 |
| 没用 sci-widget 而给了静态图 | 交互确实不必要时可降级；若你明确要「可拖」则必须可拖 |
| 3D 很简单 | 先 golden path；完整渲染可分阶段 |
